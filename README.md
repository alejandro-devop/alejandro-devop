# Hi, I'm Alejandro Quiroz 👋

**Full-Stack Developer** · Frontend Tech Lead on a global retail e-commerce platform · Medellín, Colombia 🇨🇴

I've spent over a decade turning business problems into software: ERPs for security and real-estate companies, personal finance mobile apps, admin platforms, and everything in between. Today I lead a 6-person frontend team at a global software consultancy, building high-traffic e-commerce for an international activewear brand with **Next.js** and **Node.js** every single day.

My path went bottom-up: vanilla PHP and raw SQL in 2013, my own ORM because no existing one fit, and from there to Symfony, React, React Native, and Next.js. That foundation gave me something you don't get by starting with a framework: **understanding what happens underneath**.

## 🤖 AI-augmented development

I don't just use AI to write code — I design the process that makes AI build well:

- **GitHub Copilot** integrated into my daily professional workflow for the past year.
- On personal projects I direct **AI agents (Claude Code)** through my own system of verifiable phases: architecture ADRs, a YAML phase manifest, custom slash commands that orchestrate the work, human-in-the-loop confirmation, and green test suites as the gate for every phase.
